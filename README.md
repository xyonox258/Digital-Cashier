# 💸 Digital Cashier Software v1.0.0

Digital Cashier is a secure, fully offline, daily expense tracker and financial management software built completely from scratch using pure Python. Inspired by the classic handwritten spending diary, this project brings robust modern features directly to your terminal screen.

---

## 🔥 Key Features

- **Interactive Terminal TUI:** Beautiful and highly structured terminal interface built using the `rich` library.
- **Secure User Authentication:** Encrypted user login system along with password recovery capabilities.
- **Live Financial Dashboard:** Real-time summary and deep analytics of your daily spending patterns driven by the `datetime` module.
- **Automated PDF Reports:** Generate clean, structured PDF expense summaries instantly for physical archiving or printing.
- **Advanced Encryption Protection:** Maximum data privacy achieved by encrypting local storage using `cryptography` and `json`.
- **100% Offline & Private:** Your financial data never leaves your local machine.

---

## 🛠️ Tech Stack & Dependencies

- **Core Language:** Python 3.x
- **UI/UX Framework:** `rich` (Terminal Text User Interface)
- **Security & Storage:** `cryptography`, `json`
- **Data & Reports:** `datetime`, `reportlab` (or whichever PDF library you used)

---

## 🚀 Installation & Setup

Follow these simple steps to set up and run the Digital Cashier on your local machine:

### 1. Clone the Repository
```bash
git clone https://github.com
cd Digital-Cashier
```

### 2. Install Required Dependencies
Make sure you have python installed, then run:
```bash
pip install rich cryptography reportlab
```

### 3. Launch the Application
```bash
python main.py
```
